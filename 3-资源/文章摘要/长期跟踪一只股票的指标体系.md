# 长期跟踪一只股票的指标体系

> [!summary] 核心结论
> 长期跟踪不是每季抄一遍财报，而是持续检验一条**投资假设链**：行业需求 → 公司竞争力 → 收入与利润 → 现金流 → 资产负债表 → 每股价值。指标应少而稳定，既包含结果指标，也包含能提前解释结果的经营指标；红黄绿灯只负责提醒复核，不能替代判断。

## 一、先建立“指标树”，不要先找万能比率

SEC 对 10-K 的说明指出，年报提供业务、风险、经营及财务结果，Item 7 的 MD&A 还解释管理层如何看待结果及其驱动因素；Item 8 包含利润表、资产负债表、现金流量表和股东权益变动表。因此，跟踪体系应从公司业务与风险出发，再连接到财务结果，而不是只看市盈率。[来源：SEC《How to Read a 10-K》](https://www.sec.gov/answers/reada10k.htm)

建议将指标控制在四层，每层选择 2—5 项：

| 层级 | 要回答的问题 | 通用指标 | 观察重点 |
|---|---|---|---|
| 业务驱动 | 需求和竞争力是否变强？ | 销量、用户数、客单价、续费率、产能利用率、门店数、订单/合同负债 | 选公司管理层长期披露且真正用于经营决策的指标 |
| 盈利质量 | 增长是否创造利润？ | 收入增速、毛利率、营业利润率、净利润率、分部利润 | 拆分价格、销量、产品组合、汇率、并购影响 |
| 现金与资本效率 | 利润是否转成现金？ | 经营现金流、资本开支、自由现金流、营运资本、投入资本回报率 | 区分维持性与扩张性资本开支，解释现金流与利润差异 |
| 安全与每股价值 | 下行风险是否可承受？ | 净债务、利息保障、到期债务、稀释后股数、每股自由现金流 | 关注债务期限、股权激励、增发、回购是否真正减少股数 |

IFRS 的 IAS 7 将现金流分为经营、投资和融资三类；经营现金流采用间接法时会调整非现金项目、递延和应计项目。这正是“净利润增长但现金没有增加”必须进一步核查的原因。[来源：IFRS Foundation《IAS 7 Statement of Cash Flows》](https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows.html/)

### 建议固定的 12 个核心指标

1. 收入及同比增速；
2. 核心业务销量/用户量与价格；
3. 毛利率；
4. 营业利润率；
5. 经营现金流；
6. 自由现金流（自定义并固定公式）；
7. 应收账款、存货或合同资产相对收入的变化；
8. 资本开支及其用途；
9. 净债务与未来两年债务到期额；
10. 稀释后加权平均股数；
11. 管理层指引及兑现程度；
12. 一个最能代表公司护城河的行业指标。

“投入资本回报率”“自由现金流率”等派生指标没有必要追求唯一公式；关键是把分子、分母和调整项写在指标字典里，并对历史数据按同一口径重算。

## 二、行业适配：通用财务指标之外，只选关键驱动

监管披露本身也强调分行业和分部理解。IFRS 8 要求上市实体披露不同业务活动、经济环境、产品服务、地区及主要客户的信息；分部合计还需与公司整体财务报表调节。因此，多业务公司不应只跟踪合并收入。[来源：IFRS Foundation《IFRS 8 Operating Segments》](https://www.ifrs.org/issued-standards/list-of-standards/ifrs-8-operating-segments/)

| 行业 | 优先补充指标 | 典型风险 |
|---|---|---|
| 软件/SaaS | 年度经常性收入、续费/留存、剩余履约义务、销售效率、股权激励/收入 | 公司可能改变 KPI 定义；增长被高股权激励和稀释抵消 |
| 消费/零售 | 同店销售、销量与价格拆分、库存周转、单店经济模型 | 促销拉动收入但侵蚀毛利；库存增长快于销售 |
| 制造/半导体 | 出货量、平均售价、产能利用率、在建工程、资本开支、订单 | 周期高点利润被误当长期盈利；扩产领先需求过多 |
| 银行 | 净息差、信贷增速、不良率、拨备覆盖、CET1、流动性 | 会计利润稳定但资产质量恶化 |
| 保险 | 保费增长、综合成本率、赔付率、准备金发展、投资组合收益 | 通过偏乐观准备金假设提前确认利润 |
| REIT/地产 | 出租率、同店净营业收入、租约到期、净债务、FFO/AFFO 口径 | 只看净利润忽略折旧与资产处置，但也不能忽略真实资本开支 |
| 矿业/能源 | 产量、单位成本、储量寿命、维持性资本开支、实现价格 | 商品价格掩盖运营退化；资源量不等于经济可采储量 |
| 医药 | 在研项目阶段、入组进度、监管节点、现金消耗与现金跑道 | 二元临床风险；以“调整后利润”淡化研发成本 |

行业阈值应优先来自适用监管要求，而不是跨行业套用。例如 Basel III 将杠杆率定义为一级资本除以风险暴露，并规定国际活跃银行 3% 的最低要求；监管最低线只能作为“红线底板”，不能等同于值得投资的安全水平。[来源：BIS Basel Framework《LEV20》](https://www.bis.org/basel_framework/chapter/LEV/20.htm) 对矿业公司，SEC Regulation S-K Subpart 1300 要求在矿业经营对业务或财务状况重要时披露相关矿产信息，因此储量、品位、成本假设和技术报告比通用 PE 更接近核心驱动。[来源：SEC《Modernization of Property Disclosures for Mining Registrants》](https://www.sec.gov/resources-small-businesses/small-business-compliance-guides/modernization-property-disclosures-mining-registrants-small-entity-compliance-guide)

## 三、数据来源与更新频率

| 频率 | 首选一手资料 | 要更新的内容 |
|---|---|---|
| 实时/事件触发 | 交易所公告、监管文件、公司 IR 公告、8-K 或当地等价文件 | 并购、融资、管理层变动、重大减值、诉讼、指引调整 |
| 每季度 | 10-Q/中期报告、业绩发布材料、电话会文字稿中的公司原话 | 核心指标、指引、红黄绿状态、假设变化 |
| 每年 | 10-K/年报、审计财务报表、代理声明 | 五年基线、分部结构、风险因素、薪酬激励、会计政策、资本配置 |
| 每月或每季 | 官方行业/监管数据 | 行业需求、价格、库存、利率、监管资本等外部驱动 |

对美股可用 SEC EDGAR 的 `companyfacts` API 获取单家公司全部 XBRL 概念，用 `frames` API 获取按年度或季度对齐的事实；但公司财年可能不按自然季度，且标签可能变化，自动化数据必须回到原始申报核对。[来源：SEC《EDGAR Application Programming Interfaces》](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)

每次更新保留三列：**原始披露值、统一口径值、调整说明**。不要覆盖旧数据；定义变化时记录生效季度，并视情况重算历史。

## 四、红黄绿阈值：用“多重基准”而非魔法数字

下面是可执行的自建方法，不是监管或会计准则给出的投资建议：

1. **建立基线**：至少取一个完整行业周期；若历史不足，先用 12 个季度，并标记置信度低。
2. **同时比较四个基准**：公司自身历史区间、管理层指引、同行同口径、债务契约/监管最低线。
3. **阈值看方向与持续性**：单季轻微偏离通常黄灯；连续两季恶化、偏离扩大或投资逻辑关键条件失效才转红。
4. **领先与滞后指标配对**：例如订单/收入、存货/毛利率、用户留存/收入、逾期率/信用损失。
5. **每个灯号绑定动作**，避免只做颜色装饰。

| 状态 | 建议判定 | 必做动作 |
|---|---|---|
| 🟢 绿 | 处在自有历史正常区间，方向符合投资假设，且现金与利润互相印证 | 维持跟踪，记录支持证据 |
| 🟡 黄 | 一项关键指标偏离计划或历史区间；口径改变；解释不足；领先指标转弱但财务结果尚未恶化 | 阅读脚注和电话会解释，做情景分析，下季设复核点 |
| 🔴 红 | 核心假设被事实推翻；关键指标连续恶化；触及契约/监管线；现金、债务或治理风险可能不可逆 | 重做估值与下行情景，明确持有理由是否仍成立 |

SEC 的 MD&A 指引要求公司讨论已知且可能对流动性、资本资源或经营结果产生重大影响的趋势、不确定性和承诺，并强调披露应平衡呈现成功与未达目标之处。跟踪表中的黄灯栏可直接对应这些“趋势与不确定性”，而不是只记录管理层给出的乐观解释。[来源：SEC《Commission Guidance Regarding MD&A》](https://www.sec.gov/rules-regulations/2003/12/commission-guidance-regarding-managements-discussion-analysis-financial-condition-results-operations)

## 七、常见会计口径陷阱

- **自由现金流并无唯一口径。** SEC 的 Non-GAAP 指引称其“通常”为经营现金流减资本开支，同时提醒该指标不必然代表可自由支配现金。必须保存公司的调节表，并另算一个自己的固定口径。[来源：SEC《Non-GAAP Financial Measures C&DIs》，Question 102.07](https://www.sec.gov/rules-regulations/staff-guidance/corporation-finance-interpretations/non-gaap-financial-measures)
- **“调整后”项目可能年年发生。** SEC 要求非 GAAP 指标与最可比 GAAP 指标调节；不应让非 GAAP 指标比 GAAP 指标更显著。跟踪时统计每类调整连续出现的年数，并把反复出现的重组、股权激励等视为经营成本候选。[同上，Questions 100.01、102.10]
- **分部口径会改变。** IFRS 8 要求分部结构改变时重述可比信息，若无法重述则需披露。横向比较前应确认分部定义、内部利润口径和调节项一致。[来源：IFRS 8 标准正文，第 28—30 段](https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2023/issued/part-a/ifrs-8-operating-segments.pdf?bypass=on)
- **每股增长可能掩盖稀释。** 同时跟踪净利润、稀释 EPS 和稀释后股数；IAS 33 要求稀释 EPS 将具有稀释作用的潜在普通股纳入加权平均股数。[来源：IFRS Foundation《IAS 33 Earnings per Share》，第 36—38 段](https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2022/issued/part-a/ias-33-earnings-per-share.pdf?bypass=on)
- **季度年化易受季节性和营运资本影响。** 优先比较同比、过去十二个月和完整年度；若公司财年不是自然年，按报告期而非日历硬拼。
- **并购增长不等于内生增长。** 将收入增速拆成有机增长、并购、汇率和处置影响；同时观察商誉、无形资产与后续减值。
- **阈值不能脱离商业模式。** 高库存对扩产备货与需求积压的含义相反；低资本开支可能代表轻资产，也可能代表延迟维护。灯号必须附文字解释和反证条件。

## 八、首次建立与持续维护清单

- [ ] 写出 100 字以内的投资逻辑，以及 3 个可证伪条件。
- [ ] 阅读最近 3—5 年年报中的业务、风险、MD&A、财务报表及脚注。
- [ ] 建立指标字典：名称、公式、单位、来源页码、GAAP/非 GAAP、口径变化。
- [ ] 选 8—12 个核心指标，其中至少 2 个领先经营指标、2 个现金/资产负债表指标。
- [ ] 拉取至少 12 个季度数据，保留原始值和统一口径值。
- [ ] 为每项指标设历史基线、指引基线、同业基线和硬性安全线。
- [ ] 给每个黄灯和红灯写明复核动作，不自动触发买卖。
- [ ] 每季在财报发布后更新；重大公告事件触发更新；每年重做投资假设与指标选择。
- [ ] 所有数字链接到监管申报或公司 IR 原文，不以行情软件摘要替代。
- [ ] 每年检查指标是否仍能解释价值创造，删除失去解释力的指标但保留历史记录。

> [!warning] 边界
> 本笔记是一套研究与记录方法，不构成买卖建议。监管最低要求、历史分位数和同行均值都不是内在价值，也不能替代对商业模式、治理和估值的判断。
