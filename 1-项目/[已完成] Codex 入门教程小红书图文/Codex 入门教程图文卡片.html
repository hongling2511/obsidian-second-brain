Codex 零基础入门02 / 09
选择入口

新手从桌面 App 开始

你能同时看见文件、权限和改动，出错时也更容易定位。

  1. 01桌面 App界面直观，适合第一次上手
  2. 02IDE 扩展适合经常在编辑器里写代码的人
  3. 03CLI适合熟悉终端和命令行的人

入口没有高低之分，先选你看得懂、敢检查的那个。

Codex 零基础入门03 / 09
拆分工作

项目是目录
任务是一条工作线

比如做个人主页，别把所有要求一次塞进同一条任务。

01

搭出页面和基础结构

02

修改介绍和项目文案

03

检查问题和无关改动

一条任务只处理一个目标，后面更容易追问、审查和返工。

Codex 零基础入门04 / 09
权限与安全

权限先用默认设置

先看懂它想做什么，
再决定是否放行。

  • 它准备修改哪些文件？
  • 它为什么要运行这条命令？
  • 操作是否超出当前项目？

熟悉工作方式后，再按可信项目和具体任务调整权限。

Codex 零基础入门05 / 09
提示词模板

第一条指令
照着这个结构写

目标、上下文、约束、完成标准，四件事说清楚。

在当前项目里做一个极简个人主页。包含个人介绍、项目列表和联系方式。不要修改无关文件。完成后启动本地预览，并告诉我查看地址。

“帮我做个网站”也能开始，但上面这版更容易一次做对。

Codex 零基础入门06 / 09
计划模式

复杂任务
先别急着改文件

方向还没想清楚时，先让 Codex 说明它准备怎么做。

  1. 01准备做什么
  2. 02会动哪些文件
  3. 03分几步完成
  4. 04怎样验证结果

计划没问题，再开始执行，返工会少很多。

Codex 零基础入门07 / 09
结果验收

“已完成”
不等于验收通过

不要只看结论，要看证据。

  • 文件真的生成了吗？
  • 页面或文档能打开吗？
  • 有没有改到无关内容？
  • 测试或基础检查通过了吗？

还可以另开一条任务，只审查这次改动，不要直接修。

Codex 零基础入门08 / 09
第一次上手

记住这一套就够了

选项目→说清任务→先看计划→检查权限→验收结果

新手最常见的三个坑

  1. 01一个任务塞进很多目标
  2. 02需求只有一句模糊描述
  3. 03不看改动就直接接受

第一次练手：整理资料、生成文档，或者做一个简单网页。
